# C 语言学后总结

一份写给「学过一遍 C，但知识点不扎实」的人的错题与知识补漏笔记。全部内容来自本人学习过程中的真实踩坑、提问与刷题经历，按「症状 → 病因 → 药方」的方式记录，方便快速定位问题。

## 内容概览

| 部分 | 内容 | 说明 |
| --- | --- | --- |
| 第一部分 | 错题清单 | 语法符号、输入输出、数组字符串、循环、编译环境、思维方式、文件与二进制，附高频复发榜与弯路档案 |
| 第二部分 | 我提过的问题（Q&A） | 11 类共 **111 个问题**（Q1–Q111），按知识主线排列 |
| 第三部分 | 函数速查 | stdio / string / math / stdlib / ctype / time 等头文件下 **89 个常用函数**的用法与返回值 |
| 第四部分 | 不容易背的硬知识 | 格式符、转义字符、类型范围、运算符优先级、位运算、内存对齐、补码与大小端、预处理等 24 个专题 |
| 第五部分 | 常见刷题题型与解法 | 字符串、双指针、循环分支、递归、排序、指针、结构体、动态内存、文件、项目实战 |

## 适合谁

- 已经学过一遍 C 语言，但语法细节、指针、文件、内存部分还不踏实的人
- 准备考试 / 蓝桥杯，想快速过一遍高频易错点的人
- 希望有一份「按错误现象查答案」的手册，而不是从头读教材的人

## 使用建议

1. 先看第一部分，对照自己的习惯，把中招的坑标出来
2. 写代码报错时，按症状在错题清单和第四部分里检索
3. 忘了某个函数怎么用，查第三部分；忘了某道题的套路，查第五部分
